# Dining Dollar Tracker

## Overview
This simple project, made for Purdue students, is used to track how you're spending your dining dollars over the semester. 

## Usage
- When you first run the code, it asks for your meal plan and saves it's starting dining dollar amount. This way, you only have to enter it once.
- On subsequent runs of the code, it will ask you how much you spent to enter a transaction. Entering a number will save the transaction to a list in transactions.json along with the current date.
- To skip entering a transaction, you can input any non-number in the terminal and the program will go straight to displaying the statistics and graph.
